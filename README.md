# Страны и столицы — Европа и Азия

Мобильное веб-приложение (PWA) для заучивания положения стран Европы и Азии на карте и их столиц.
Часть света переключается кнопкой в верхней панели.
Чистые HTML/CSS/JS без сборки и бэкенда, работает офлайн, ставится на экран «Домой» iPhone.

## Структура

```
index.html             разметка, мета-теги iOS
style.css              стили, светлая/тёмная тема, safe-area
app.js                 логика: карта, режимы, Лейтнер, статистика
sw.js                  service worker (кэш всех файлов)
manifest.webmanifest   манифест PWA
data/countries.json    страны Европы: название, столица, ISO-код, регион
data/asia.json         страны Азии (alt — допустимые варианты написания столицы)
data/europe.geojson    контуры Европы (Natural Earth через world-atlas)
data/asia.geojson      контуры Азии
vendor/d3.min.js       D3 v7.9.0 локально
icons/                 PNG 180/192/512 + maskable
tools/                 одноразовые генераторы данных/иконок и смоук-тест (приложению не нужны)
```

## Запуск локально

```bash
npx http-server -p 8080 -c-1     # или: python3 -m http.server 8080
```

Откройте http://localhost:8080. Service worker работает только по `http://localhost` или `https://`.

Проверка (Chromium через Playwright): `cd tools && npm i && node smoke-test.mjs`.
Пересборка данных и иконок: `node build-geo.mjs`, `node build-icons.mjs`.

После изменения файлов увеличьте `VERSION` в `sw.js`, иначе установленные копии продолжат брать старый кэш.

## Бесплатный деплой

**Netlify Drop** (проще всего): откройте https://app.netlify.com/drop и перетащите папку проекта
(можно без `tools/`). Через несколько секунд получите адрес вида `https://имя.netlify.app`.

**GitHub Pages**: репозиторий → Settings → Pages → Source: «Deploy from a branch» →
ветка `master`, папка `/ (root)` → Save. Адрес: `https://<логин>.github.io/<репозиторий>/`.
Все пути в приложении относительные, поэтому работа из подпапки не требует настроек.

## Установка на iPhone

1. Откройте адрес приложения в **Safari** (не в Chrome — на iOS добавлять на экран умеет только Safari).
2. Нажмите **«Поделиться»** (квадрат со стрелкой вверх) → **«На экран „Домой“»** → «Добавить».
3. Запустите с иконки — откроется на весь экран без адресной строки.
4. Один раз откройте при интернете: файлы закэшируются, дальше работает в авиарежиме.

Прогресс хранится в `localStorage` этого устройства (у установленного приложения он отдельный от вкладки Safari).

Данные карты: Natural Earth (общественное достояние).
